# GNOT · Trading System V1.2

SOXL、AGQ、LABU、MSTU 统一交易执行与复盘网站。采用独立公开 GitHub 仓库与 GitHub Pages；源文件位于 `dist/`，发布时生成 `.pages/`。原投资台账只作跳转，不修改、不共享或覆盖其数据。

公开页面：[GNOT 交易工作台](https://blackrimmedlol-code.github.io/gnot-soxl-trading/#workspace)

## 运行与检查

不需要安装依赖。页面采用 ES modules，需通过 HTTP 访问，不能用 `file://` 双击代替部署。

```bash
npm run check
npm test
# 本机普通开发环境可用：
python3 -m http.server 8000 --directory dist
```

托管在仓库子路径时，资源均采用相对路径，适用于 `/gnot-soxl-trading/`。哈希路由无需服务端重写。

## 计算口径

- 整股数向下取整，不改变技术止损、计划金额或 1% 风险上限。
- 新计划初始风险 = 计划整股数 ×（计划入场 − 技术止损）。新流程只需实际成交价格与整股数，界面不显示费用或滑点记录提示。
- 价格 R = 入场 − 止损；1.5R／2R 价格由价格距离推导。目标收益风险比要求至少 1.5。
- 每轮初始风险固定在计划保存时；实际 R = 实际成交盈亏 ÷ 该风险。真实成交不同于计划股数时也不自动重写分母。
- 部分卖出以卖出时的移动加权成本兑现。新成交内部费用为 0，不把未录费用冒充已扣费用。导入的旧费用与冻结初始风险保留，更正旧成交不清零费用。卖出不改变剩余股数的每股均价。
- 未实现盈亏 = 剩余股数 × 手动价格 − 剩余持仓成本（旧记录含已录费用）。不虚构后续卖出费；没有估值显示未知。
- 加仓风险使用剩余资金风险与整轮止损后损失两者的较大值，不利用已实现利润掩盖剩余仓位风险。
- 胜率、平均 R、期望与连续亏损统计主动 SOXL／AGQ／LABU／MSTU 的已退出轮，支持合计与分标的筛选；持平进入胜率分母。部分兑现纳入累计已实现收益。
- 规则遵守率仅统计已退出且已明确评价的轮；自动违规标记不会被人工「遵守」冲掉。
- 账户回撤单独使用真实手动账户权益快照。按份额净值法排除净出入金，不把 SOXL 已实现余额冒充完整账户权益。
- 5% 回撤暂停，需要写复核结论；新快照再次触及 5% 需重新复核。曾触及 10% 后 V1 不自动解除，系统重评需另行确认。
- 连续两轮止损暂停美东当日新开仓。以完整退出且净亏损、含止损成交识别止损轮；中国时间用于录入展示，美东日期用于当日暂停。

以上纪律是用户确认的 V1 制度与初始测试假设，不代表回测或收益保证。普通止损不保证价格，SOXL 的每日目标不等于多日累计三倍。

## 数据与备份

- `localStorage` 持久化，键为 `gnot-soxl-v1`。没有后台数据库、行情接口、券商权限或前端 Token。
- 同设备同浏览器刷新可保留；跨浏览器、设备、域名不自动同步。
- 正式修改前保留最近 5 版本机备份；计算器草稿自动写入但不挤占五版备份。
- JSON 与完整备份 CSV 无损恢复全部数据。完整备份 CSV 是 `record_type,id,payload_json` 三列，保持嵌套清单、成交与复盘。
- 可读流水 CSV 是单独分析格式，不能用其恢复完整交易轮。券商任意 CSV 没有隐式字段猜测。
- 导入有结构、重复 ID、数量、资金口径与成本检验。按 ID 合并时内容冲突立即中止；明确整库恢复才覆盖。
- Web Locks + 版本号保护同浏览器多标签页。没有 Web Locks 时仍检查版本号，但不承诺所有浏览器都能阻止极窄窗口的并发写入。
- 数据损坏不默默清空；保留原文供下载与恢复。配额写入失败不改变旧主数据。
- 备份是明文，包含完整交易金额；由用户放在自己的可信存储里。

## GitHub Pages 迁移

仓库使用 `.github/workflows/pages.yml`：推送 `main` 后自动检查、测试，再运行 `npm run build:pages` 生成并发布 `.pages/`。打包时为样式、图标、脚本及模块引用添加由资源内容生成的版本号，避免更新后仍沿用旧样式缓存；开发源文件保持普通相对路径。Pages Source 设为 GitHub Actions。部署不需要在前端放任何 Token。

独立仓库名称为 `gnot-soxl-trading`。应用无第三方运行时依赖，静态资源使用相对路径。公开的是网站源码和默认规则；用户浏览器中的交易数据不会被推送到仓库。

新站首次打开没有交易数据。网站域名迁移会改变本机存储空间：旧站先导出 JSON，在新站导入，不会自动搬迁历史记录。
