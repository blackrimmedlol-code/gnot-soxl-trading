# GNOT · 交易工作台 V3.3

[线上工作台](https://blackrimmedlol-code.github.io/gnot-soxl-trading/#workspace)

固定战场 **SOXL / GDXU / BITX**。按2026-10-18 v1.1纪律计算结构/ATR止损、+2R全额止盈、参考股数和可执行股数，同时保留真实成交、日志、表现、完整备份。小时趋势可读取原策略台的已发布快照；30分钟突破、报价与账户资料仍需独立核对，不自动下单。

## 使用

1. 首次核对v1.1启用净值；每日填写并确认当日开盘净值（初始$30,000）与可用现金。
2. 选择标的，填买入参考价、已收盘1小时ATR(14)、含信号K线的近6根30分钟最低价，立即显示止损、+2R及单笔参考股数。
3. 展开买点核对，填写已收盘小时收盘价/EMA20/EMA50、此前6根30分钟最高价、30分钟信号收盘价及两个收盘时间。满足趋势、突破、信号有效期、组合额度和暂停条件后才显示可执行股数。
4. 实际成交后用“带入实际买入记录”，核对真实成交价和整股数后保存；不会下单。实际偏离可勾选后如实记录。
5. 已有持仓须更新5分钟内的手动价格及时间；历史标的可在详情更新估值。未知持仓估值或止损风险不会按零处理。

价格计算始终可用；市场休市、数据缺失或过期时，参考结果不能当成实时买点。入场窗口使用America/New_York时区，自动处理夏令时；正常休市与半日市按NYSE2026–2028公布日历处理，额外临时停市无法自动获知。

## 新纪律

- 小时趋势：已收盘收盘价 > EMA50，且EMA20 > EMA50。
- 30分钟收盘突破此前6根最高价，不包含信号K线；信号时间10:30–15:00 ET，只在下一根30分钟内有效。
- 初始止损 S = min(L − 0.1A, P₀ − 1.5A)。L含信号K线，A为已收盘小时ATR14。距离 > 3A放弃。
- 成交后保留S，实际均价P对应目标P+2(P−S)；初始R=实际股数×(P−S)。+1R不操作；小时趋势失效或休市前按规则退出。
- 常规单笔风险1.5%、合计3%；半档0.75%／1.5%；单只市值25%；已确认趋势合格0/1/2/3只，总仓位上限0/25/50/60%。三笔都可能亏损，浮盈不释放原风险预算。
- 连续两笔亏损跨日累计，持平不清零；两笔亏损或偏离后完整休息下一个正常交易日，并记录至少10字复盘后恢复。恢复不加倍风险。

完整规则见 [TRADING_RULES.md](dist/TRADING_RULES.md)。这些参数未经回测验证，不代表预测盈利；计划风险也不是跳空后的实际亏损上限。

## 收盘风险档位与复盘

v1.1启用净值须本人核对，不由默认资金或旧快照推测。每个交易日登记合并策略账户的收盘净值；缺少最近或中间收盘资料时禁止新增。外部现金流逐笔提供发生时刻、金额与发生前净值，按前后收益衔接；内部划转不重复计算。更正保留旧值，若影响已完成的恢复判定，则须撤回失效恢复操作并重新复核。

收盘回撤6%进入半档并保持，9%暂停；不因反弹自动提档。回撤暂停至少休息下一完整正常交易日、清仓并处理原因后，才能以最新收盘净值开启新的半档周期。恢复常规必须回撤<3%、连续5笔合规完整交易合计R>0、期间没有暂停，并在周末确认。周期重启不抹去全历史回撤。连续亏损／违纪恢复独立检查，不解除已有半档。

股数说明显示四项额度及主要限制，允许主动减股数。交易日志每笔一行，细节展开；已确认违纪与资料待核对分开。表现首页显示本周守纪率、平均实际R、周期回撤和档位；旧交易仍可查询。止损后下一完整交易日收盘后可补充“是否重新出现完整买点”的手动观察。规则依据由完整MD载入，按条目展开。

## 数据兼容

沿用 `gnot-soxl-v1` / schemaVersion 1、本机五版本备份、多标签页冲突保护。旧四标的、固定比例快照、成交、费用、初始R及隐藏的未成交档案保持原样。新结构/ATR交易采用独立模式快照；更正实际价格时不下移原冻结止损。

JSON和完整备份CSV包含工作台行情快照与恢复复盘。合并记录保留当前计算输入，恢复复盘按时间合并，冲突中止；整库恢复可迁移所有状态。实际成交仍保留偏离标记，不借更正或手动自评清除。

成交保存后可用现金回到待核对状态，不能把日志估算当作券商实际现金。新纪律从首次使用生效时刻计数，不追溯触发生效前旧交易的暂停。

新用户账户历史基准为$30,000；已有用户历史基准不自动重写。工作台当前净值使用用户提供的$30,000起始设置，之后需手动按实更新；现金不从成交日志猜测。

## 三标的自动小时快照

工作台从原策略台us-market-dashboard的`trading-trends.json`读取SOXL/GDXU/BITX已收盘1小时趋势及Wilder ATR。保持原四次任务；浏览器可见时每分钟只检查已发布文件，手动“同步最新快照”也不触发新任务或模型。

新用户默认自动模式，旧版已填完整小时数据默认保留手动模式。顶部可切换；原手动输入保留。自动模式提供小时收盘价、EMA20、EMA50、ATR和真实K线收盘时间；买价、结构低点、30分钟突破、最新报价、现金及账户风险仍独立核对。自动数据过期、缺失或休市只作参考，不放行新开；新小时完成后旧小时快照失效。已保存交易的初始止损、目标、R和预算不随同步改写。

来源为Yahoo产品自身60m正式盘OHLC，连续250根预热；EMA采用SMA种子，ATR采用Wilder14，尾盘缩短的提供方小时K线纳入并标记。图表软件口径不同可切换手动核对。来源失败显示不可用，不能以公共快照推测用户账户或自动交易。


## V3.3 执行证据与轻量复盘

- 计算结果首先解释允许新开0股的主要原因，并提供对应核对入口。缺失、过期、未来数据标记为待核对，不与已确认趋势不合格混用；四项额度可展开查看，不改变现有股数算法。
- 保存买入后回到当前持仓卡，直接查看实际买价／股数、初始止损、+2R价格、初始1R金额和现有退出提示。网站不推定券商保护订单已设置。
- 从计算器带入记录时，保存当时的核对时间、来源、条件状态与允许股数。详情展示原始行情和规则版本；后续同步不会改写。旧记录没有核对时间时不补造，晚于成交的核对也不标为事前通过。
- 原复盘表增加一个主要执行标签：无偏离、抢跑、追损、未按规则提前退出、扩大风险、漏执行、其他偏离。默认未标注，不能视为无偏离。确认偏离计入违纪，沿用原暂停机制；修改备注或自评不清除已确认标签，也不把旧偏离重复计作今天的新事件。
- 日志可按标签查找；表现页的执行诊断并列全部实盘、守纪、违纪和待核对的笔数／平均实际R。标签筛选只作用下方明细，不隐藏全量结果。守纪子集不能替代包含漏做信号的策略回测。
- 沿用原存储键、schemaVersion与完整JSON／CSV，新增核对与标签记录一并保留。未修改交易纪律v1.1、旧成交金额、初始止损、历史费用或自动更新任务。
