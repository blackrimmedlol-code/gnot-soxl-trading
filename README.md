# GNOT · 交易工作台 V3

[线上工作台](https://blackrimmedlol-code.github.io/gnot-soxl-trading/#workspace)

固定战场 **SOXL / GDXU / BITX**。按2026-10-18纪律计算结构/ATR止损、+2R全额止盈、参考股数和可执行股数，同时保留真实成交、日志、表现、完整备份。当前无行情接口或自动下单，所有行情由用户手动填写。

## 使用

1. 核对当日开盘净值（初始$30,000）与可用现金。
2. 选择标的，填买入参考价、已收盘1小时ATR(14)、含信号K线的近6根30分钟最低价，立即显示止损、+2R及单笔参考股数。
3. 展开买点核对，填写已收盘小时收盘价/EMA20/EMA50、此前6根30分钟最高价、30分钟信号收盘价及两个收盘时间。满足趋势、突破、信号有效期、组合额度和暂停条件后才显示可执行股数。
4. 实际成交后用“带入实际买入记录”，核对真实成交价和整股数后保存；不会下单。实际偏离可勾选后如实记录。
5. 已有持仓须更新5分钟内的手动价格及时间；历史标的可在详情更新估值。未知持仓估值或止损风险不会按零处理。

价格计算始终可用；市场休市、数据缺失或过期时，参考结果不能当成实时买点。入场窗口使用America/New_York时区，自动处理夏令时；正常休市与半日市按NYSE2026–2028公布日历处理，额外临时停市无法自动获知。

## 新纪律

- 小时趋势：已收盘收盘价 > EMA50，且EMA20 > EMA50。
- 30分钟收盘突破此前6根最高价，不包含信号K线；信号时间10:30–15:00 ET，只在下一根30分钟内有效。
- 初始止损 S = min(L − 0.1A, P₀ − 1.5A)。L含信号K线，A为已收盘小时ATR14。距离 > 3A放弃。
- 成交后保留S，实际均价P对应目标P+2(P−S)；初始R=实际股数×(P−S)。+1R不操作；小时趋势失效或休市前按规则退出。
- 单笔风险0.5%、合计1.5%；单只市值25%；已确认趋势合格0/1/2/3只，总仓位上限0/25/50/60%。三笔都可能亏损，浮盈不释放原风险预算。
- 连续两笔亏损跨日累计，持平不清零；两笔亏损或偏离后完整休息下一个正常交易日，并记录至少10字复盘后恢复。恢复不加倍风险。

完整规则见 [TRADING_RULES.md](dist/TRADING_RULES.md)。这些参数未经回测验证，不代表预测盈利；计划风险也不是跳空后的实际亏损上限。

## 数据兼容

沿用 `gnot-soxl-v1` / schemaVersion 1、本机五版本备份、多标签页冲突保护。旧四标的、固定比例快照、成交、费用、初始R及隐藏的未成交档案保持原样。新结构/ATR交易采用独立模式快照；更正实际价格时不下移原冻结止损。

JSON和完整备份CSV包含工作台行情快照与恢复复盘。合并记录保留当前计算输入，恢复复盘按时间合并，冲突中止；整库恢复可迁移所有状态。实际成交仍保留偏离标记，不借更正或手动自评清除。

成交保存后可用现金回到待核对状态，不能把日志估算当作券商实际现金。新纪律从首次使用生效时刻计数，不追溯触发生效前旧交易的暂停。

新用户账户历史基准为$30,000；已有用户历史基准不自动重写。工作台当前净值使用用户提供的$30,000起始设置，之后需手动按实更新；现金不从成交日志猜测。
