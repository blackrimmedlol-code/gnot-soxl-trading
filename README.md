# GNOT · 执行记录与复盘 V2

SOXL、AGQ、LABU、MSTU 的真实成交记录工具。输入买入价与整股数，自动换算金额、固定 −1R 止损及 +2R 全额退出参考价，一次保存完成买入记录。后续买入独立记账。保留原投资总台账的跳转链接。

公开页面：[GNOT 执行记录](https://blackrimmedlol-code.github.io/gnot-soxl-trading/#workspace)

## 运行与部署

无第三方运行时依赖；ES modules 需通过 HTTP 访问。

```bash
npm run check
npm test
npm run build:pages
# 普通开发环境可运行：
```

源文件在 `dist/`。GitHub Actions 推送 `main` 后执行语法检查、全部测试、Pages 打包与部署。发布目录 `.pages/` 的资源和模块引用带内容摘要版本号，避免沿用旧缓存；哈希路由与相对路径支持仓库子路径。前端不放 Token 或 API Key。

## 计算口径

- 金额 = 实际整股数 × 实际成交价。止损 = 买入价 ×（1 − 固定比例）；目标 = 买入价 + 2 ×（买入价 − 止损）。计算保留八位小数，价格展示最多四位，小于 $1 时最多八位。
- 初始 1R = 买入股数 ×（买入价 − 初始止损）。新买入首次保存时冻结参数和 R；更正实际买入的录入错误会按本笔参数快照同步退出价与 R。旧交易更正不改写原基准。
- 实际 R = 实际成交盈亏 ÷ 本笔初始 1R。卖出可以部分执行，移动加权成本正确计算已实现和剩余成本；新规则的部分或提前退出记录偏离。跳空损失可能超过 −1R。
- 后续右侧买入独立建立记录，同标的可有多个独立持仓；四标的共同预算仍累计检查。新规则不向既有交易追加买入。
- 新成交不要求费用或滑点字段。导入旧记录保留其原有记账字段，更正不会清除历史费用。已有偏离不会通过更正或人工自评自动消失。
- 胜率、平均 R、期望与连续亏损按主动标的完整退出统计；持平进入胜率分母，历史分类不纳入，部分兑现计入已实现收益。少于 30 笔完整退出提示样本不足。
- 遵守率仅按明确完成自评的已退出记录计算，成交偏离标记优先。事后补录不伪造已完成事前检查。
- 账户最大回撤根据手动权益快照，用份额净值排除出入金，不把交易盈亏余额冒充账户权益。未记录的盘中回撤无法捕获。
- 两笔连续亏损止损触发美东当天暂停；5% 回撤暂停复核，新快照再触及需重新复核；曾触及 10% 需重评，不自动解除。

## 数据与兼容

继续使用 `gnot-soxl-v1`、schemaVersion 1，本机同浏览器刷新保留。没有后台同步；不同设备、浏览器或域名需通过完整 JSON／CSV 迁移。用户交易数据不上传公开仓库。

正式修改保留最近五版本机备份；草稿自动保存不挤占备份。Web Locks 与版本号保护同浏览器多标签页，冲突时中止写入。损坏数据可下载原文，配额失败保留旧数据。

JSON 与完整备份 CSV 无损恢复全部嵌套字段；可读成交流水 CSV 仅供分析。导入校验结构、ID、数量、风险及成本；按 ID 合并遇到内容冲突立即中止，整库覆盖需明确确认。备份是明文，建议指定主设备并定期保存到可信存储。
