# V1.0 验收记录

记录日期：2026-10-11（中国时间）。

## 已执行

- Node.js 语法检查：`dist/app.js`、`core.js`、`storage.js`。
- 66 项自动测试通过。包括 120 组多次成交现金流恒等校验。
- 整股向下取整、预算、预估费用、指定价格与 R 目标、压力止损价。
- 不合规计算不修改输入；实际滑点后的目标空间与风险重新检查。
- 部分卖出与再次加仓后的加权成本、全退出净收益、实际 R。
- 超卖、小数股、负费用、重复 ID、清仓后重开同一轮、止损下移拒绝。
- 主动 SOXL 与历史分类隔离；历史未知风险保持未知。
- 胜率、期望 R、合规率、连续亏损与止损暂停口径。
- 高点回撤、份额净值出入金调整、5% 暂停复核、10% 停止开仓。
- JSON／完整备份 CSV 无损往返、冲突合并中止、可读流水的文本公式处理。
- 本机五版备份、数据损坏保留原文、配额失败保留旧数据、版本冲突中止。
- 静态 HTML：66 个唯一 ID、引用资源存在、viewport 标签。
- 响应式结构包含 480／760／960／1250 px 断点；窄屏单列、可滚动表格、44 px 操作控件及移动输入字体。

## 未完成的验证

- 当前环境没有 Sites 所要求的 control-browser 能力。未启动替代浏览器或冒充真实截图验收。
- 桌面和 iPhone 的实际渲染、点击、输入、文件下载／恢复、刷新保持尚待真实浏览器验收。
- CSS 静态审查与 Node 测试不等于视觉验收，UI 可靠性置信度低于财务纯函数。
- 用户 GitHub 新建仓库、Actions 实际运行与 GitHub Pages 发布没有执行；现有连接没有暴露对应管理能力。
- 私有 Work 网站的发布结果单独以托管平台部署状态记录；部署成功不替代上述浏览器验收。

## 实盘前最小核对

1. 工作台输入权益 25,000、金额 5,000、买入 50、止损 48，核对 100 股、投入 5,000、计划风险 200、目标 53／54。
2. 止损改为 47，核对风险 300，显示「本次交易不符合规则」，金额仍为 5,000。
3. 在独立测试记录中：买 100 @50；卖 50 @54；卖 50 @51。核对全退出成交盈亏 250（未扣手续费）、实际 R 为 1.25。之后删除测试轮，避免混入真实统计。
4. 导出 JSON，刷新，核对数据；另一设备导入后检查轮数／股数。不要把独立设备误当自动同步。
5. 2026 年 11 月正式开始记录时，添加初始账户权益快照，日后及时更新才能识别账户回撤。

## 简化界面复核

- 计算器不再显示费用或滑点输入；新计划费用模拟均为 0，1% 风险上限和技术止损保持原值。
- 实际成交流水不要求记录手续费、计划成交价或滑点；按实际价格和整股数计算。
- 旧备份中的费用、计划参考价、初始 R 保留；不改写历史收益。
- 增加 1% 精确边界／超预算、实际价部分退出 R、旧备份兼容测试。
