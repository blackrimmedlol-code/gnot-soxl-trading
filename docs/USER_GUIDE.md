# GNOT · 执行记录与复盘使用说明

## 记录买入

1. 选择 SOXL、AGQ、LABU 或 MSTU。
2. 填实际买入价、整股数和一句话买入理由。金额自动换算；只填价格也能先看到止盈止损参考。
3. 点击「保存买入记录」。一次保存完成，不再单独建立提前计划或再次确认成交。

成交时间默认现在，账户权益沿用最近设置，可展开更改。首次买入以 $5,000 为投入参考，实际股数由你输入；本笔与账户合计风险仍检查 1% 预算。已真实发生的偏离成交，明确勾选后照实记录。

| 标的 | 止损比例 | 全额止盈比例 |
| --- | ---: | ---: |
| SOXL | −2.15% | +4.30% |
| AGQ | −1.20% | +2.40% |
| LABU | −2.55% | +5.10% |
| MSTU | −3.30% | +6.60% |

这是 2026-10-13 方案的固定参考值，不随行情自动调整，也不是已经回测的盈利规律。−1R 止损、+2R 全部退出；+1R 不操作。后续右侧买入在首页独立登记，不合并至原记录，仍检查所有持仓共同预算。网站不下单。

## 记录卖出与复盘

持仓卡片点「记录卖出」，自动带入全部剩余股数。输入实际卖出价，选择卖出原因并保存。分次或部分成交按真实股数修改；实际结果可以偏离固定退出方式，网站保留标记，不强行改为理想结果。

详情显示每笔金额、剩余股数、平均成本、已实现盈亏和实际 R。完成退出后填写执行自评、评分或复盘备注。已有偏离标记不能通过自评「遵守」抹掉。

录错时在流水点「更正」：新规则买入按本笔保存的参数同步修正参考价和初始 R；旧版交易保持其原止损、目标和 R。历史记录不会因新版参数被重新计算退出制度。更正成交保留已有偏离记录。

未实现盈亏需要在详情中「更新手动估值」，网站不猜测实时价格。

## 账户表现与纪律

表现页支持四标的合计与分标的复盘。胜率只用主动已退出交易，持仓中与旧持仓历史排除；样本不足时明确提示。

权益快照填写真实账户总权益和距上一快照的净出入金：入金为正、出金为负，已包含在总权益内。账户回撤按快照与出入金调整计算，不随标的筛选改变，也不能反映未记录的盘中低点。

连续两笔止损亏损暂停美东当日新开仓；从权益高点回撤 5% 暂停复核，10% 停止主动开仓并重新评估。

## 保存与迁移

交易数据保存在当前网站、当前浏览器，刷新保留；不上传到公开 GitHub 仓库，也不自动跨设备同步。

建议指定一台主设备，每周及换设备前导出完整 JSON。另一设备导入后核对记录。完整备份 CSV 也可恢复；可读成交流水 CSV 只用于分析。

按 ID 合并遇到不同内容会中止；整库恢复会明确覆盖。最近五版本机备份可撤销错误，但清除浏览器数据时也会丢失，不能替代设备外备份。旧版未成交档案虽然不出现在执行日志里，仍保留在完整备份中。

普通止损无法保证成交价；实际跳空退出可能超过 −1R。所有统计以真实成交为准，不生成预计年化收益。
