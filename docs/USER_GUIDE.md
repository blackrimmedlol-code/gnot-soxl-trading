# GNOT · 三标的交易工作台

## 先算价格

首页只看 SOXL、GDXU、BITX。先核对当日开盘账户净值和当前可用现金；新纪律初始净值为$30,000。

选择标的，填写三项：

1. 买入参考价：准备使用的限价，不是历史持仓成本。
2. 1小时 ATR(14)：同一标的已收盘1小时K线的Wilder ATR数值，不能填日线ATR或波动百分比。
3. 近6根30分钟最低价：包含刚完成的信号K线。

右侧立即显示初始止损、+2R、参考股数、对应风险和投入。价格轴显示−1R / 买入参考 / +2R关系。计算结果不代表当前已满足买入条件。

## 再核对买点

展开“核对买点与数据时间”，填写小时收盘价、EMA20、EMA50、小时收盘时间、此前6根30分钟最高价、信号30分钟收盘价和信号收盘时间。时间按中国时间填写，系统按美东时区处理。

此前6根最高价**不包含**信号K线；结构最低价**包含**信号K线，两个范围不同。只用正常交易时段已收盘数据。小时数据90分钟内有效，信号收盘时间10:30–15:00 ET，信号只在下一根30分钟内有效。

“单笔参考股数”只考虑单笔0.5%风险和单只25%市值；“当前允许新开”还检查趋势、突破、数据时间、现金、组合仓位与风险、已有同标的持仓和暂停期。任一条件缺失或不满足，当前允许股数为0，并列出原因。

其他战场未核对时，只使用已确认合格数量对应的较低仓位上限，不假定其合格。三只全有信号也不是各买一万美元；实际股数仍按额度的最小值计算。

## 记录实际成交

“带入实际买入记录”只填表、不保存成交，更不会下单。实际发生后再核对真实价格、整股数、理由和时间并保存。参考值与真实成交可不同，止损保留原结构/ATR计算快照，目标按真实买价计算。

发生了偏离或数据无法完整核对时，网站先显示提示；明确勾选后可如实保存，保留标记供复盘。不能把事后输入伪装成事前确认。

新纪律成交保存后可用现金清空为“待核对”，需按券商实际值更新后才再允许开仓；网站不从日志猜测账户现金。

## 看持仓与卖点

持仓卡片一直保留本笔止损与目标。展开计算器的“更新当前手动价格”，填写报价及时间，更新相应持仓的手动估值；也可在记录详情更新手动估值。用于新增额度及价格卖点的报价有效期为5分钟，过期后显示待更新，不据此放行新增。

最新手动报价触及止损或+2R、小时趋势失效、休市前退出时间到时，持仓卡片显示相应动作。网站不会监控实时价格或自动卖出，券商有效退出订单仍须自行设置。

卖出时点“记录卖出”，核对实际价格和股数、选择止盈/止损/结构或休市退出原因。默认全部剩余股数，允许如实记录部分成交及偏离。已存在的偏离不会因为更正成交或人工自评变成遵守而消失。

更正新纪律买价或股数时，保留原冻结止损，按真实价格重新计算本笔R与目标；已经卖出的历史成交也重新核对。旧版固定比例交易沿用原规则，不套用新ATR参数。

## 连续亏损与复盘

新纪律自本工作台首次使用的生效时刻起计数，不追溯处罚生效前旧交易。两笔亏损跨日期、标的、账户累计；盈利清零，持平不清零。新纪律偏离也触发复核。

暂停后，触发当天不再开仓，完整休息下一个正常交易日。复盘至少10字，不能跳过休息期；两者满足才恢复。暂停时已有仓位继续执行退出，不清除止损。NYSE正常日历已核对2026–2028年，临时停市须自行核对。

## 备份与旧数据

沿用原网站与原存储键，旧交易、固定比例快照、费用、初始R、历史分类和旧未成交档案均保留。本机记录不自动跨设备同步。

完整JSON或完整备份CSV可迁移全部交易、工作台行情输入、恢复复盘与历史数据。按ID合并保留当前计算输入、合并恢复复盘；冲突中止。整库恢复会明确覆盖，建议先导出当前数据。

现有账户的历史权益基准不自动改写；工作台的当日净值独立按实更新。未登记账户持仓、未知止损或过期估值均需先核对，不能用零风险假设绕过预算。
